Create your mod

Build a mod with the guide below, or with an AI coding agent and our prompt. Try it in the builder, then send it as a pull request so every user can pick it.

  1. Read the guide
  2. Copy the agent prompt
  3. Load your mod
  4. Open a pull request

On this page

    Prompt for an AI coding agent

    Paste it into your coding agent, in your clone of the repository, on a new branch from dev. It makes the agent read the rules first, work only in your mod's folder, test in the emulator and prepare the pull request description for you to review.

    agent-prompt.md

    Load your mod (.json)

    Choose your mod's patch.json. It is checked here and stored only in this browser: it then appears in Create your OS, marked as local, until it is merged and the site is updated.
