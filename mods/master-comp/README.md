# master-comp

Bus compressor on the **FX track bus**. Compresses the tracks routed to the FX track, together. The name stays master-comp for compatibility.

## Use

FX track → **SYN** page:

| Knob | Range | Saved |
|---|---|---|
| A `THR` | threshold, −60 … 0 dB | kit (pattern) |
| B `ATK` | attack, 0.1 … 100 ms | kit (pattern) |
| C `REL` | release, 10 ms … 2 s | kit (pattern) |
| D `MUP` | makeup, 0 … +24 dB (capped by the master volume range) | kit (pattern) |
| E `RAT` | `OFF`, 1.5:1, 2:1, 3:1, 4:1, 6:1, 8:1, 16:1, 20:1 | kit (pattern) |
| F `GR` | gain-reduction meter, read only: full bar = no reduction, empty = −18 dB | — |
| G `COMP` | ON/OFF for A/B comparison; keeps RAT and the other settings | not saved, starts ON |
| H `DRIVE` | stock | stock |

- Values in real units: `-30dB`, `25ms`, `4:1`.
- Saved per pattern (with the kit), or globally when *SYN global* is on.
- Existing projects load with the compressor off.

`[!]` Tracks not routed to the FX track are neither detected nor compressed (checked on the device, v0.9).

`[!]` Toggling *global* for the **external input** mixer also copies these settings. They share that kit block.

`[!]` No dry/wet: not possible on a VCA.

## How it works

| Part | Detail |
|---|---|
| Type | Feed-forward VCA compressor. Detects on ADC 6/7 (FX track bus *before* its VCAs). Applies gain by scaling those VCAs' control voltages (CV 35/36), once per audio block (~1.5 kHz). |
| Detector | Block peak (32 samples) → log2 → threshold/ratio → peak hold with release → attack smoothing → makeup → exp. Digitakt mk1 curves. Tables generated from `dsp.py`. |
| Closed form (v0.8.1) | Hold and attack filters solved over the block (r³², a³², one cross term; recomputed only when a knob moves). vs per-sample detector: 0.03 dB median, ~1 dB worst, slightly more reduction on high frequencies. |
| Ids | 514–520 ([idspace](../idspace)). Routed to our storage by hooks on the kit get/set functions ([vparams](../vparams)). Up to v0.9: 262–268, the MIDI machine's CC Select page. |
| Storage | 4 unused words of the external-mixer block of the kit. |
| Text | One formatter per id, 128-entry tables generated by `make_patch.py` from `dsp.py`. |
| Boot setup | Page slots, formatters and knob graphics set once by a stub on the page initializer (`0x4019531A`), not in the audio interrupt. |
| Cost per block | ~100 instructions off, ~600 on (v0.8.0: ~2,000). Constants recomputed only when stored values change. |

`[!]` Up to v0.8.0 the mod used hidden ids that the OS shows as aliases (59 = GAIN of the track EQ filters, 122 = REV on MIXER page 2, 91/101 = LFO SLEW, 127 = PAN). Those knobs showed the compressor.

Details: [docs/audio-path.md](../../docs/audio-path.md), [docs/ui-parameters.md](../../docs/ui-parameters.md).
